# Universal Chunking Engine (.NET 9)

موتور اولیه و قابل توسعه برای استخراج ساختار کتاب‌ها و آماده‌سازی متن برای RAG فارسی.

## امکانات این نسخه
- معماری چندلایه Domain / Application / Infrastructure / API
- دریافت فایل‌های TXT، DOCX و PDF دارای لایه متنی
- نرمال‌سازی پایه فارسی و تشخیص زبان
- تشخیص تیترهای فارسی، عربی، انگلیسی و شماره‌گذاری‌شده
- تشخیص پاراگراف، فهرست، نقل‌قول، پاورقی و نشانه‌های آیات
- استخراج جدول‌های DOCX با حفظ ردیف، سلول و ادغام افقی
- ساختار سلسله‌مراتبی فصل‌ها و بخش‌ها
- چانکینگ با حفظ مرز پاراگراف‌ها، اندازه هدف، حداکثر اندازه و هم‌پوشانی
- API برای بارگذاری، تحلیل ساختار و تولید چانک
- تست‌های واحد پایه

## عمداً خارج از محدوده
- **هیچ OCR در پروژه وجود ندارد.** PDF اسکن‌شده بدون لایه متنی استخراج نمی‌شود.
- اتصال به SQL Server، Qdrant، BGE-M3، Reranker و Ollama در این نسخه انجام نشده؛ این‌ها مراحل بعدی pipeline هستند.
- تشخیص معنایی با LLM هنوز پیاده‌سازی نشده؛ راهبرد فعلی ساختاری/قاعده‌محور است.
- ترتیب بین پاراگراف و جدول در DOCX در `ParsedDocument.Blocks` حفظ می‌شود؛ تبدیل جدول به چانک متنی در این نسخه به شکل متنی و با برچسب سلول‌ها انجام می‌شود.

## پیش‌نیاز
- .NET 9 SDK

## اجرا
از پوشه ریشه:

```bash
dotnet restore
dotnet build
dotnet test
dotnet run --project src/UCE.Api
```

API به صورت پیش‌فرض روی آدرس‌های تعیین‌شده توسط ASP.NET Core اجرا می‌شود.

## API
- `GET /health`
- `POST /api/documents/analyze` با `multipart/form-data` و فیلد `file`
- `POST /api/documents/chunk` با `multipart/form-data` و فیلد `file` و پارامترهای اختیاری `targetTokens`, `maxTokens`, `overlapTokens`

## نمونه curl
```bash
curl -F "file=@book.docx" http://localhost:5000/api/documents/analyze
```

## نکات دقت
1. TokenCount در این نسخه تخمینی و مبتنی بر شمارش واژه/قطعه‌های متنی است؛ معادل tokenizer اختصاصی مدل نیست.
2. تشخیص تیتر و نوع بلوک heuristic است و باید روی نمونه‌های واقعی کتاب‌های شما ارزیابی و تنظیم شود.
3. شماره صفحه برای DOCX معمولاً در دسترس نیست؛ برای PDF شماره صفحه استخراج می‌شود.
4. جدول‌های DOCX استخراج می‌شوند؛ جدول‌های PDF در این نسخه به صورت متن صفحه باقی می‌مانند و ساختار سلولی آن‌ها بازسازی نمی‌شود.
5. فایل‌های ورودی باید از نظر اندازه و امنیت در لایه استقرار محدود شوند؛ این نسخه محدودیت حجم پایه API دارد.
